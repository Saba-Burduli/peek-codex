# TUI behavior

Sessions is the Bubble Tea/Bubbles root view. Its short introduction identifies loaded and project counts; the Bubbles status bar shows matching sessions. Each row provides an age, project folder, provider, status, optional branch, and saved session title for quick comparison of recent and older history; agent-output previews are not shown. A captured home-directory working path is labelled `Workspace` instead of an account-name folder. `Up`/`k` and `Down`/`j` move one row; `Home` and `End` jump to the first and last visible rows. `/` starts Bubbles fuzzy search across project and session metadata (not previews); typing filters immediately, `Backspace` edits, and `Esc` clears the search. While search is active, every printable key is query text and arrows/Home/End navigate its filtered rows. `Enter` opens a read-only project detail view. In details, the Bubbles viewport scrolls long content, `Esc` returns to Sessions; `q` exits when not typing search and `Ctrl-C` exits from every view.

The detail view opens with a project summary derived from loaded safe metadata: local session count, latest activity, provider set, status set, and captured branch set. It then shows the selected session's saved title, project, path, branch, provider, status, relative timestamps, and sanitized session ID. It does not render agent-output previews, load conversation turns, mutate sessions, or invoke `codex resume`.

Rows collapse gracefully in narrow terminals: optional branch metadata is placed last and disappears before project, provider, status, and title. Bubbles truncates long row text by terminal display-cell width. Session text, fatal errors, and partial-result warnings have control characters and line breaks replaced before rendering and are capped at 240 characters.

Bubble Tea owns terminal modes and the alternate screen; the program closes the app-server on normal exit, interruption, and errors. Non-TTY execution fails before terminal mutation with an actionable message.
